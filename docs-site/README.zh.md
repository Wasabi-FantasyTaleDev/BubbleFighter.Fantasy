# 文档站

站点使用 Vue 3 和 VitePress。公开内容维护在 `../docs/`，`pages.json` 明确选择十一个指南路由、四种语言。英文使用 `.md`，简体中文使用 `.zh.md`，繁体中文使用 `.zh-tw.md`，韩文使用 `.ko.md`。繁体中文遵循站点现有用语，界面标签为中文（繁体）。

## 开发与构建

安装 Node.js 和 npm，在本目录执行：

```sh
npm ci
npm test
npm run dev
npm run build
```

开发服务绑定 `127.0.0.1:4273`。内容同步在生成页面前检查全部翻译及元数据。新增或重命名路由时同步修改 `pages.json`、主题导航和四种语言的源文档。本地指南链接会转换为对应语言的路由；私有或未发布路径会被拒绝。生成的 Markdown、依赖及构建产物不提交。

## 静态托管

部署到仓库子路径时，在 `npm run build` 前将 `DOCS_BASE` 设为带首尾斜线的路径，例如 `/project/`；域名根目录使用 `/`。审查 HTML、搜索资源和媒体后，只发布 `.vitepress/dist/`。发布前按相同 base 路径构建并预览。仓库不会自动发布站点。

启动器图标和背景视频是本地公开资源，公开发布前须核实再分发权利。Windows 下载和 Linux 指令在真实入口配置前继续标注即将提供。
