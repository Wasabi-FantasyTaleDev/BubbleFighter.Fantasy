## 未发布 — 2026-10-25（UTC+08:00）

- 2026-10-25：恢复全部 22 组已配置的 kr-1256 AI 房间预设，包含阵容等级、角色、颜色、服装、武器与原生物品修改器。房间与回合视图中的 AI 昵称按每位接收者的启动器语言显示；韩语名称保留预设拼写，其他语言使用本地化的难度标题与角色名。修改器目标无效、本地化缺失或外观数据超限时在激活阶段失败。实际进游戏的外观验收仍待完成。
- 2026-10-25：通过原生添加/移除请求加入可选的 kr-1256 AI 房间席位，包含独立的席位外观记录、控制者迁移以及按角色的移动、计分与生命/重置状态。机器人保留席位但不占用网络会话，也不会阻塞人类玩家的加载屏障。可选的 `profiles/kr-1256/ai-rooms.patch.yaml` 为原生预设选择提供可配置的服务器配装；完整官方装扮与真实客户端玩法验收仍未验证。初始教学关卡路线不变。
- 2026-10-25：移除未使用的 `match-relay` 插件与 `InGame.Wire` 程序集。共用房间绑定改经封包表读写回合结果；房间会话模型移入房间库，中继会话键移入契约程序集。既有的类型化玩法路径与 profile 配置保持不变。
- 2026-10-24：把最后的兼容插件并入共用行。删除的插件 ID：`dialect.modern.messages`、`dialect.inventory-actions` 与 `dialect.customized-keys`；其封包改为 `dialect.messages` 的选项（`inventory_actions`、`customized_keys`）。封包字节无变化；补丁中列出任何被删除行的运营者必须删除该行，否则 profile 组合会以未知插件名失败。

## 未发布 — 2026-10-20（UTC+08:00）

- 2026-10-22：新增启动器自建商店指南，说明总目录、客户端 Profile、插件元数据、工具依赖与限制，以及总目录最后发布的流程。
- 每个版本都会发布 Windows x64、Windows ARM64、Linux x64 与 Linux arm64 的预编译包。在 Windows 上解压 ZIP 后双击 `BubbleFighter.Fantasy.Host.exe`：安装向导随即启动并在浏览器中打开，启动出错时错误会一直显示到按下任意键。在 Linux 上，`curl -fsSL https://wasabi-fantasytaledev.github.io/install.sh | bash` 即可安装服务器，加上 `--docker` 则在容器中运行，只有再加上 `--with-mysql` 时才附带 MySQL。
- KR2026 的商店购买遵循客户端自身商店表中的物品条款：限时物品会到期，永久物品保持永久，条款拒绝的购买会收到失败回复且不扣费。含有耐久计数物品的六个套装在该版本的规则确定之前暂时无法购买。
- KR2026 商店的所有封包现在都按名称从该版本的 opcode 表查找。打开礼物盒的已发送列表不再触发购买，退款请求也不再收到物品卡片的应答。
- KR2026 的新账号现在会进入客户端自带的角色创建画面，与旧版本一致。KR2026 也会在玩家离线期间物品到期后显示原生的到期通知。
- 修复旧版本中持有未记录期限物品的账号无法登录的问题，以及 cn-404、cn-406、cn-408 与 cn-706 的首次登录问题。
- KR2026、cn-774 与 tw-454 改由共用的登录适配器登录。使用自定义补丁的运营者请注意：已移除的 `dialect.modern.messages` 登录选项列在仓库的 `CHANGELOG.md` 中；补丁中仍有已移除的键时，启动会失败，删除后即可恢复。
- 启动检查现在会验证绑定读写的每个封包字段的类型，因此封包表若改变了字段类型，会在服务器启动时报错，而不是在收到第一个封包时出错。
- 故障排查页说明了 `NU1900` 包审计错误，以及无法连接 nuget.org 时如何构建。
