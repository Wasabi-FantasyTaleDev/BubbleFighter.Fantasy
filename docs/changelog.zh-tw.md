## 尚未發布 — 2026-10-25（UTC+08:00）

- 2026-10-25：還原全部 22 組已設定的 kr-1256 AI 房間預設，包含陣容等級、角色、顏色、服裝、武器與原生物品修改器。房間與回合檢視中的 AI 暱稱依每位接收者的啟動器語言顯示；韓文名稱保留預設拼寫，其他語言使用在地化的難度標題與角色名稱。修改器目標無效、在地化缺失或外觀資料超限時在啟用階段失敗。實際進遊戲的外觀驗收仍待完成。
- 2026-10-25：透過原生新增/移除請求加入選用的 kr-1256 AI 房間席位，包含獨立的席位外觀記錄、控制者遷移以及依角色的移動、計分與生命/重置狀態。機器人保留席位但不佔用網路工作階段，也不會阻擋人類玩家的載入屏障。選用的 `profiles/kr-1256/ai-rooms.patch.yaml` 為原生預設選擇提供可設定的伺服器配裝；完整官方裝扮與真實用戶端玩法驗收仍未驗證。初始教學關卡路線不變。
- 2026-10-25：移除未使用的 `match-relay` 模組與 `InGame.Wire` 組件。共用房間繫結改經封包表讀寫回合結果；房間工作階段模型移入房間程式庫，中繼工作階段金鑰移入合約組件。既有的型別化玩法路徑與 profile 設定保持不變。
- 2026-10-24：把最後的相容模組併入共用列。刪除的模組 ID：`dialect.modern.messages`、`dialect.inventory-actions` 與 `dialect.customized-keys`；其封包改為 `dialect.messages` 的選項（`inventory_actions`、`customized_keys`）。封包位元組無變化；修補檔中列出任何被刪除列的營運者必須刪除該列，否則 profile 組合會以未知模組名稱失敗。

## 尚未發布 — 2026-10-20（UTC+08:00）

- 2026-10-22：新增啟動器自建商店指南，說明總目錄、用戶端 Profile、模組中繼資料、工具相依需求與限制，以及總目錄最後發布的流程。
- 每個版本都會發布 Windows x64、Windows ARM64、Linux x64 與 Linux arm64 的預先編譯套件。在 Windows 上解壓縮 ZIP 後按兩下 `BubbleFighter.Fantasy.Host.exe`：安裝助理隨即啟動並在瀏覽器中開啟，啟動出錯時錯誤會一直顯示到按下任意鍵。在 Linux 上，`curl -fsSL https://wasabi-fantasytaledev.github.io/install.sh | bash` 即可安裝伺服器，加上 `--docker` 則在容器中執行，只有再加上 `--with-mysql` 時才附帶 MySQL。
- KR2026 的商店購買遵循客戶端自身商店表中的物品條款：限時物品會到期，永久物品保持永久，條款拒絕的購買會收到失敗回覆且不扣款。含有耐久計數物品的六個套裝在該版本的規則確定之前暫時無法購買。
- KR2026 商店的所有封包現在都依名稱從該版本的 opcode 表查找。開啟禮物盒的已寄出清單不再觸發購買，退款請求也不再收到物品卡片的回覆。
- KR2026 的新帳號現在會進入客戶端內建的角色建立畫面，與舊版本一致。KR2026 也會在玩家離線期間物品到期後顯示原生的到期通知。
- 修正舊版本中持有未記錄期限物品的帳號無法登入的問題，以及 cn-404、cn-406、cn-408 與 cn-706 的首次登入問題。
- KR2026、cn-774 與 tw-454 改由共用的登入轉接器登入。使用自訂修補檔的營運者請注意：已移除的 `dialect.modern.messages` 登入選項列在儲存庫的 `CHANGELOG.md` 中；修補檔中仍有已移除的鍵時，啟動會失敗，刪除後即可恢復。
- 啟動檢查現在會驗證繫結讀寫的每個封包欄位的型別，因此封包表若改變了欄位型別，會在伺服器啟動時報錯，而不是在收到第一個封包時出錯。
- 疑難排解頁說明了 `NU1900` 套件稽核錯誤，以及無法連線到 nuget.org 時如何建置。
