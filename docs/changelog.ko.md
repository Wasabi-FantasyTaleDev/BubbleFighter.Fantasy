## 미출시 — 2026-10-20 (UTC+08:00)

- 모든 릴리스에 Windows x64, Windows ARM64, Linux x64, Linux arm64용 사전 빌드 패키지가 게시됩니다. Windows에서는 ZIP의 압축을 풀고 `BubbleFighter.Fantasy.Host.exe`를 더블클릭하면 설치 도우미가 시작되어 브라우저에서 열리며, 시작 오류는 키를 누를 때까지 화면에 남습니다. Linux에서는 `curl -fsSL https://wasabi-fantasytaledev.github.io/install.sh | bash`로 서버를 설치하고, `--docker`를 붙이면 컨테이너로 실행하며, `--with-mysql`을 추가할 때만 MySQL도 함께 실행합니다.
- KR2026 상점 구매가 클라이언트 자체 상점 시트의 아이템 조건을 따릅니다. 기간제 아이템은 만료되고, 영구 아이템은 영구로 유지되며, 조건에 맞지 않는 구매는 실패 응답을 받고 요금이 부과되지 않습니다. 내구도 계수 아이템이 포함된 세트 여섯 개는 이 빌드의 규칙이 정해질 때까지 구매할 수 없습니다.
- KR2026 상점은 이제 모든 패킷을 빌드의 opcode 테이블에서 이름으로 찾습니다. 선물함의 보낸 목록을 열어도 더 이상 구매가 일어나지 않으며, 환불 요청에 아이템 카드로 응답하지 않습니다.
- KR2026의 새 계정은 이제 이전 빌드처럼 클라이언트 자체의 캐릭터 생성 화면을 거칩니다. KR2026은 플레이어가 접속하지 않은 동안 아이템이 만료되면 기본 만료 알림도 표시합니다.
- 이전 빌드에서 기간이 기록되지 않은 아이템을 가진 계정의 로그인 문제와 cn-404, cn-406, cn-408, cn-706의 첫 로그인 문제를 수정했습니다.
- KR2026, cn-774, tw-454는 공용 로그인 어댑터로 로그인합니다. 사용자 지정 패치를 쓰는 운영자는 참고하세요. 제거된 `dialect.modern.messages` 로그인 옵션은 저장소의 `CHANGELOG.md`에 나와 있으며, 제거된 키가 패치에 남아 있으면 삭제할 때까지 시작이 실패합니다.
- 시작 검사가 이제 바인딩이 읽거나 쓰는 모든 패킷 필드의 형식을 확인하므로, 패킷 테이블이 필드 형식을 바꾸면 첫 패킷이 아니라 서버 시작 시에 실패합니다.
- 문제 해결 페이지에 `NU1900` 패키지 감사 오류와 nuget.org에 연결할 수 없을 때 빌드하는 방법을 추가했습니다.

## 미출시 — 2026-10-18 (UTC+08:00)

- 4개 언어 가이드를 검증 가능한 절차와 함께 확장했습니다. 설치와 빠른 시작은 소스 빌드와 아직 공개되지 않은 빌드 패키지를 구분하고, 설정은 profile 구성, 환경 변수, 포트, 영속성, 클라이언트 데이터를 다루며, 배포는 Docker Compose, 백업, 업그레이드와 롤백을 설명합니다. 문제 해결은 증상 → 확인 → 원인 → 해결 순서로 구성했습니다.
- 플러그인 가이드에 실행 가능한 첫 플러그인 절차를 추가하고 SDK 프로토콜 참고 문서에 언어별 빠른 시작, 기능 협상, 적합성 테스트 내용을 보강했습니다.
- 영어와 중국어 README를 다시 작성하여 요구 사항, Windows/Linux 빠른 시작, Docker Compose, 클라이언트 데이터 경계와 문서 진입점을 담았습니다.
- 현재 코드와 맞지 않던 설명을 수정했습니다. 아직 공개되지 않은 다운로드와 설치 진입점은 계속 "곧 제공"으로 표시합니다. 이번 변경은 문서에 한정되며 실행 동작은 바뀌지 않았습니다.
- 4개 언어로 런처 가이드를 추가했습니다. 동반 Fantasy Tale Launcher의 클라이언트 빌드, 세션과 로그인 티켓 모델, hook 플러그인, 배포 경계, 그리고 운영자를 위한 서버 `launcher.http` API(HTTP 426 버전 게이트, JSON 호환 규칙, 티켓 보안 경계 포함)를 다룹니다. 문서만 변경되었습니다.

- 취소와 시간 초과 후에도 시작된 작업의 소유권을 유지하고 새 정의 게시 후 시작 시 선택 순서를 수정했습니다.

- 플러그인 및 SDK 가이드에 등록 예제, 수명 규칙과 아직 구현되지 않은 네이티브 동등성 범위를 명시했습니다.
