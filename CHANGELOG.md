- 2026-10-20: Release packages. `tools/build-release.py --version <x.y.z> --output <dir>` publishes the host framework-dependent for win-x64, win-arm64, linux-x64 and linux-arm64, checks each executable's machine type and that no runtime or operator file (`.env`, `local.patch.yaml`, state, logs, client data) is included, refuses an untracked `src`, `profiles`, `packets` or `data` tree, and writes reproducible archives with versionless names (`bubblefighter-fantasy-<rid>.zip|.tar.gz`, so `releases/latest/download/<name>` always names the newest), `SHA256SUMS` and `install.sh`. `deploy/install.sh` installs the Linux package into `releases/<tag>` behind a `current` link with `state/` kept across upgrades, verifies the checksum, installs the ASP.NET Core Runtime 10 locally when it is missing, lists the new release's profiles before switching to it, and writes a `bff` launcher; `--service` adds a systemd unit, `--docker` builds a local image from the package and runs the server alone (SQLite or an existing database), `--with-mysql` adds a MySQL 8.4 container (host networking for the server, MySQL on loopback, generated passwords in a 0600 `.env`, kept on upgrade), `--from <dir>` installs offline and `--admin-port`/`--mysql-port` move the ports. The documentation site serves the script at `/install.sh`. Starting the Windows executable with no arguments from its own console now opens the WebUI in the default browser (new `admin.http` option `open_browser`, which the host sets only in that case; `setup.yaml` reads `BFF_OPEN_BROWSER`) and keeps the window open after a failure.
